# 📊 Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes customer shopping behavior, purchasing patterns, product performance, subscription behavior, discount usage, customer segmentation, and revenue contribution.

The project uses **Python for data cleaning and transformation, SQL Server for solving business questions, and Power BI for creating an interactive dashboard.**

---

## 📌 Project Overview

The objective of this project is to transform raw customer shopping data into meaningful business insights using an end-to-end analytics workflow.

The project focuses on:

- Customer demographics
- Purchase behavior
- Product performance
- Subscription behavior
- Discount usage
- Shipping preferences
- Customer segmentation
- Product ratings
- Revenue by category
- Revenue by age group
