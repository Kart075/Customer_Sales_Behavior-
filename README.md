# 📊 Customer Shopping Behavior Analysis

An end-to-end data analytics project focused on understanding customer shopping behavior, purchasing patterns, product performance, subscription behavior, discount usage, customer segmentation, and revenue contribution.

The project uses **Python for data cleaning and transformation, SQL Server for solving business questions, and Power BI for creating an interactive dashboard.**

---

# 📋 Project Overview

This project analyzes a customer shopping dataset to understand **how customers purchase, what products and categories perform well, how subscription and discount behavior relate to purchasing, and which customer segments contribute to sales and revenue.**

The project follows a complete **ETL and Business Intelligence workflow**.

First, the raw dataset was cleaned and transformed using **Python and Pandas**. Missing values were handled, column names were standardized, and new features such as **Age Group** and **Purchase Frequency in Days** were created.

The cleaned data was then loaded into **SQL Server**, where SQL queries were used to solve different business questions related to **revenue, sales, customer segments, product ratings, discounts, shipping methods, subscriptions, and repeat customers**.

Finally, the analyzed data was used in **Power BI** to build an interactive **Customer Behavior Dashboard**. The dashboard provides KPIs and visualizations for customer count, average purchase amount, average review rating, category-wise revenue and sales, age-group analysis, and subscription distribution.
